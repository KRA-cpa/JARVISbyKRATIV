# Daloy logo mark

**Chosen (1 Nov 2026):** a "D" with a stream running through it — *daloy* is Tagalog for "flow". Replaces the generic
ticket icon used while the product was called TicketFlow.

| File | Use |
|---|---|
| `daloy-mark.svg` | Master drawing (32×32 viewBox) |
| `src/components/shared/BrandMark.js` | Same drawing as a React component (headers, login) |
| `public/favicon.svg`, `public/favicon.ico` (16–64), `public/logo192.png`, `public/logo512.png` | Browser tab and home-screen icons, rendered from the master |
| `options-compared.png` | The three options at 16 / 28 / 48 / 96 px, light and dark |

**Colours:** tile `#2563EB` (Tailwind blue-600, the app's primary), D `#FFFFFF`, stream `#93C5FD` (blue-300).

**Why B over the alternatives:** A (a path through three steps) reads as a stock chart going up; C (three waves) is the
generic "water / ≈" symbol and hard to own. B is the only one tied to the name and stays legible at 16 px.

**Before printing or registering it:** run a trademark image search (IPOPHL, WIPO Global Brand Database, Class 42).
Letter-plus-wave marks are common; the design has not been cleared.
