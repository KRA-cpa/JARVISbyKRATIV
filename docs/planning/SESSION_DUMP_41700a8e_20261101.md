## §6 Gotchas learned
- **Git Bash `TZ=Asia/Manila date` silently prints UTC.** That is why the first v10.2 copy was stamped `20261031_1744`. Take UTC+8 stamps from PowerShell (`Get-Date -Format yyyyMMdd_HHmm`). Node's ICU handles `TZ=Asia/Manila` fine, so the test runs are not affected.
- **The AppScript files are CRLF.** Appending an LF block mixes endings and breaks exact-match edits. `scratchpad/patch.py` normalizes to CRLF and converts the edit strings.
- **`git checkout <sha> --` with no path detaches HEAD.** It happened once (tree clean, nothing lost). Never use it as a no-op.
- **Vercel previews are protected** (a Vercel SSO redirect). The real URL comes from the GitHub deployment status (`environment_url`); branch aliases over 63 characters are shortened with a hash and can't be guessed.
- **A fail-closed gate can leak.** Refusing on a missing record told callers that a record exists (A21). The gate now leaves missing / hidden records to their handlers; three older suites caught it.
- **A regex reading the second argument** must not stop at a `''` in the first (`requireFeature(String(x || ''), 'key')`).
- **Inline Python heredocs in the Bash tool are fragile** with backticks and quotes. Write the script to the scratchpad and run it.
