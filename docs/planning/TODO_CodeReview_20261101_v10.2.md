## Checked, no finding

- **tickets_per_month in the lock:** `requireLimit(... 'tickets_per_month')` and `countTicketUsage` both run inside `createTicket`, which `doPost` runs under `withScriptLock`; `nextSequenceValue` re-reads `sequence_counters` and invalidates it (A14), so two concurrent creates can't both take the last slot; a refused ticket is not counted (test); chained tickets (`requesterIsTarget`) are never refused but are counted; nothing can throw between the counter and the `appendRow`. The month key uses the country calendar zone (`calendarTz`, design §3).
- **`skipPlanLimit`:** an `options` argument, not read from any payload; the only caller passing it is `acceptPendingInvite` (scope problem in CR6-06). `replaceUserRoles` at the limit is net zero (the delete drops the user, the re-add fits) - probe confirmed, roles not lost.
- **In-handler refusals at the top level:** returned refusals go through `createHandlerResponse` / `createDataResponse` (`PLAN_REFUSAL_KEYS` spread: `createUserRoleAssignment`, `createUserInvite`, `createWorkflowStep`, `createCustomField`, `updateCustomField`, `setTicketTypeFeatures`, `createTicketLink`, the display-zone check); thrown ones (`createTicket`, `createTicketType` - which re-throws) reach the `doPost` catch with `code` + fields (text: CR6-15). `createTicketType`'s `createJsonResponse({ success: true })` route is not reached on a throw.
- **Display zone (U8):** the check uses the `actorId`-resolved user (A15), blank always allowed.
- **A1 / A2 / A14 / A16 / A17 / A18 / A20:** new writes are header-driven (`appendRecords`, `updateRecordFields`), the new tab only in `TABLE_SCHEMAS`, `company_subscriptions` read once per request (P10 test), days via `dayIn` / `shiftDay` in the company zone, ids from `generateId('sub')`, no duplicate definitions (`check:code-rules`). `seedCompanySubscriptions` is editor-only, dry run by default, idempotent.
- **`/plans` signed out makes no API call:** `OpenRoute` renders the page directly; `UserProvider`'s `onAuthStateChanged(null)` only dispatches `LOGOUT` (`fetchUserData` / `recordLogin` run only for a Firebase user); `DarkModeProvider` returns before `getPreferences` without `user.id`; `PlansPage` (signed out) → `PublicHeader`, `PlanCatalog`, `Footer`, `config/plans.js` import no API; `DevPanel` makes none; the plan hooks are not mounted. (Static check: `node_modules` is not installed in this container, so no browser run.)
- **plan-copy:** `src/config/plans.js` TIERS / LIMITS equal `PLAN_FEATURE_TIERS` / `PLAN_LIMITS`; every tier key has a label in `PLAN_FEATURE_GROUPS`.
- **SEED v1.2:** removal deletes only `usage:seed_co_*` counters and the seed companies' subscription rows; older AppScript files without the tab are handled.
