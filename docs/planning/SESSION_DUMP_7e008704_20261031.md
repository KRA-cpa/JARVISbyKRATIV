## §6 Gotchas learned

- **Editor ≠ deployed:** the JARVIS Admin Status shows the code saved in the editor; the web app serves the last **deployed** version - check `?action=ping`. Redeploy = Edit the existing deployment → **New version**.
- **Vercel env vars apply on the next build** - redeploy after changing them; `REACT_APP_*` values are baked into the bundle.
- **Never prefix server-only settings with `REACT_APP_`** (they would be published in the bundle).
- **A payload key named `action` replaces the route** (A13) - it caught the first v9.5 draft (`escalation_action`).
- **The live proxy POSTs every call** (secret never in a URL); a backend older than v9.4 can't serve it.
